# ExpenseIQ – Personal Expense Tracker

A professional personal expense tracking and data visualization application built using Python and Streamlit.

## Features

- Interactive dashboard for expenses, income, savings, and transactions
- Add, edit, and delete transactions
- Automatic expense categorization
- Import transactions from CSV files
- Category-wise spending analysis
- Monthly spending trends
- Payment method analysis
- Daily spending visualization
- Monthly category budgets and overspending alerts
- Download reports in CSV and Excel formats
- SQLite database for storing transactions and budgets
- Sample transaction data generation for demonstration

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SQLite
- OpenPyXL

## Run Locally

1. Clone this repository:
   `git clone https://github.com/anushkar824-glitch/Personal-Expense-Tracker.git`
2. Open the project folder.
3. Install the required libraries:
   `pip install -r requirements.txt`
4. Start the application:
   `streamlit run app.py`

## Project Purpose

ExpenseIQ demonstrates Python programming, data analysis, database management, interactive data visualization, and dashboard development through a practical personal finance application.

## Note

The application uses locally stored SQLite data and generated sample transactions for demonstration. It does not connect to bank accounts or retrieve banking information.
